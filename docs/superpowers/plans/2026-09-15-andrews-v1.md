# Andrew's v1 Implementation Plan

> **For agentic workers:** You are one of several agents working in the same checkout on `main`. Read `docs/superpowers/specs/2026-09-15-andrews-meal-prep-design.md` in full before starting. Touch only the files your task owns. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A phone-shaped Next.js prototype of a Chipotle-style meal prep ordering app for Iowa State students, working end to end in the browser with no backend.

**Architecture:** Next.js App Router pages render inside a `PhoneFrame`. All menu data is a typed TypeScript module. Pure pricing and rewards functions live in `src/lib` and are unit tested. Three React context providers wrap localStorage through one validated storage module. Every screen composes shared components from Task 0.

**Tech Stack:** Next.js 15, React 19, TypeScript, Tailwind CSS v4, `lucide-react`, Vitest, `next/font/google`.

## Global Constraints

- Only two packages beyond the `create-next-app` defaults: `lucide-react` (dependency) and `vitest` plus `@vitejs/plugin-react` and `jsdom` (dev). Nothing else without asking the orchestrator via a linkC note.
- Test-first for every function in `src/lib/`. Write the failing test, run it, implement, run it green, commit.
- Fail loud: no `try/catch` that swallows, no `?? defaultValue` that hides a corrupt store. Storage throws on invalid data.
- No `console.log`, no commented-out code, no scratch files left behind.
- Copy is sentence case. Buttons name the action: "Add to bag", "Check out", "Place order", "Reorder", "Sign in". Toasts repeat the verb: "Added to bag."
- Colors only via the tokens in `globals.css`. Fonts only via the three `next/font` variables. No hex literals in components.
- Every interactive element is at least 44×44px and has a visible cardinal focus ring.
- `npm run lint`, `npm test`, and `npm run build` pass before a task reports done.
- Commit only your own task's files. Commit message style: `feat: <what>` or `test: <what>`. Do not mention any AI tool in commits.
- Shared files are frozen after Task 0: `src/app/globals.css`, `src/app/layout.tsx`, `src/components/*.tsx` (top level), `src/data/**`, `src/lib/**`, `src/state/**`. If you need a change there, post a linkC note titled `Shared file request: <file>` and keep going on the rest.
